Arquitectura del Sistema

El SPA Management System es una aplicación SaaS multitenant diseñada para la gestión integral de centros de estética y relajación. Utiliza una arquitectura moderna basada en microservicios dockerizados con separación completa de datos entre tenants.

Configuración Docker

El sistema está completamente dockerizado. Basta con ejecutar docker-compose up -d para levantar todos los servicios.

docker-compose.yml

# docker-compose.yml - Desarrollo Local
version: '3.8'

services:
  backend:
    build:
      context: ./backend
      dockerfile: Dockerfile
    container_name: spa_backend
    ports:
      - "8000:8000"
    env_file:
      - .env
    depends_on:
      mysql:
        condition: service_healthy
      redis:
        condition: service_started
    volumes:
      - ./backend/app:/app/app  # Hot-reload
    networks:
      - spa_network
    restart: unless-stopped

  frontend:
    build:
      context: ./frontend
      dockerfile: Dockerfile
    container_name: spa_frontend
    ports:
      - "80:80"
    depends_on:
      - backend
    networks:
      - spa_network
    restart: unless-stopped

  mysql:
    image: mysql:8.0
    container_name: spa_mysql
    ports:
      - "3306:3306"
    environment:
      MYSQL_ROOT_PASSWORD: ${MYSQL_ROOT_PASSWORD}
      MYSQL_DATABASE: ${MYSQL_DATABASE}
    volumes:
      - mysql_data:/var/lib/mysql
      - ./database/init.sql:/docker-entrypoint-initdb.d/init.sql
    networks:
      - spa_network
    healthcheck:
      test: ["CMD", "mysqladmin", "ping", "-h", "localhost"]
      interval: 10s
      timeout: 5s
      retries: 5
    restart: unless-stopped

  redis:
    image: redis:7-alpine
    container_name: spa_redis
    ports:
      - "6379:6379"
    volumes:
      - redis_data:/data
    networks:
      - spa_network
    restart: unless-stopped

volumes:
  mysql_data:
  redis_data:

networks:
  spa_network:
    driver: bridge

Comandos útiles

# Levantar todos los servicios

# Detener todos los servicios

# Reconstruir sin caché

# Ver estado de los contenedores
docker-compose ps

# Acceder al backend
docker-compose exec backend bash

# Acceder a MySQL
docker-compose exec mysql mysql -u root -p

Backend API - Endpoints

API REST construida con FastAPI. Documentación automática disponible en /docs (Swagger UI) y /redoc (ReDoc).

AUTENTICACIÓN

POST /api/v1/auth/login Iniciar sesión con email y contraseña
POST /api/v1/auth/register Registrar nuevo SPA + admin
POST /api/v1/auth/refresh Refrescar token de acceso
GET /api/v1/auth/me Obtener usuario actual
PUT /api/v1/auth/change-password Cambiar contraseña

TENANTS (SOLO SUPERADMIN)

POST /api/v1/tenants Crear nuevo tenant
GET /api/v1/tenants Listar todos los tenants
GET /api/v1/tenants/{id} Obtener tenant específico
PUT /api/v1/tenants/{id} Actualizar tenant
DELETE /api/v1/tenants/{id} Soft delete tenant

USUARIOS

POST /api/v1/users Crear nuevo usuario
GET /api/v1/users Listar usuarios del tenant
GET /api/v1/users/{id} Obtener usuario específico
PUT /api/v1/users/{id} Actualizar usuario
DELETE /api/v1/users/{id} Eliminar usuario

Seguridad

El sistema implementa múltiples capas de seguridad para proteger los datos de cada tenant.

🔐 Autenticación JWT

  • Tokens con expiración configurable
  • Refresh tokens con vida más larga
  • Algoritmo HS256
  • Payload incluye tenant_id

🔑 Contraseñas

  • Hash con bcrypt (passlib)
  • Validación de fortaleza
  • Mínimo 8 caracteres
  • Mayúsculas, minúsculas, números, especiales

🏢 Multitenancy

  • Filtrado automático por tenant_id
  • Middleware de validación
  • Sin posibilidad de fuga de datos
  • UUIDs para todos los IDs

🖥️ Infraestructura

  • Contenedores no-root
  • Variables de entorno para secrets
  • Headers de seguridad en Nginx
  • Rate limiting (pendiente)

⚠️ Consideraciones de Producción

  • Cambiar SECRET_KEY por una clave segura de al menos 32 caracteres
  • Usar HTTPS en producción (configurar certificados SSL en Nginx)
  • Implementar rate limiting con Redis
  • Configurar backups automáticos de la base de datos
  • Rotar logs y configurar monitoreo
  • No exponer puertos de MySQL y Redis externamente

Inicio Rápido

Levanta todo el sistema con un solo comando. Asegúrate de tener Docker y Docker Compose instalados.

1

Clonar el repositorio

git clone https://github.com/tu-usuario/spa-management-system.git
cd spa-management-system
2

Configurar variables de entorno

cp .env.example .env
# Editar .env con tus valores (especialmente SECRET_KEY)
3

Levantar los servicios

# Desarrollo (con phpMyAdmin)
docker-compose --profile development up -d

# Producción
docker-compose -f docker-compose.yml -f docker-compose.prod.yml up -d
4

Verificar servicios

docker-compose ps
# Todos los servicios deben mostrar "healthy" o "running"

# Verificar health del backend
curl http://localhost:8000/health
5

Acceder al sistema

Frontend: http://localhost
⚙️ API: http://localhost:8000
🗄️ phpMyAdmin: http://localhost:8081
📚 Swagger UI: http://localhost:8000/docs
6
